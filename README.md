🎓 Smart Campus: All-in-One College Management & Student Productivity System

📖 About The Project

The Smart Campus is a comprehensive, web-based integrated platform designed to automate and streamline academic and administrative activities within a college environment. It eliminates the need for manual, paper-based processes and fragmented applications by bringing everything under one unified "Single Source of Truth."

Built with an emphasis on both institutional governance and student productivity, the system offers robust features ranging from smart timetable management and digital attendance to notice acknowledgements and career readiness tools.

Project By: Rahane Shubham Ashok & Wabale Ritesh Balasaheb

Institution: Shri Sadguru Gangageer Maharaj Science, Gautam Arts & Sanjivani Commerce College, Kopargaon

✨ Key Features

The platform implements strict Role-Based Access Control (RBAC), categorizing functionalities for three primary stakeholders:

🛡️ 1. Administrator Module

Dashboard Analytics: High-level view of total students, faculty, pending leaves, and active complaints.

User Management: Add, edit, or remove students and faculty members.

Department & Course Management: Configure academic departments and courses.

Notice Management: Broadcast official notices with file attachments and track acknowledgements.

Leave & Request Approvals: Digitally process and approve/reject leave and document requests.

👨‍🏫 2. Faculty Module

Smart Timetable: View course-wise and class-wise schedules dynamically.

Enterprise Attendance: Digitally mark and track student attendance with real-time analytics.

Resource Sharing: Upload notes, study materials, and assignments for specific courses/classes.

Calendar Management: Track academic events, practicals, and meetings.

🎓 3. Student Productivity Module

Personalized Dashboard: Real-time visibility into attendance percentage, pending notices, and active leaves.

Academic Tracking: View and download uploaded study resources and notes.

Administrative Requests: Digitally apply for leaves, raise complaints, or request official documents.

Notice Acknowledgement: View official circulars and digitally acknowledge them to ensure compliance.

Career Readiness: Access to interview preparation tools and personal document organization features.

🚀 Installation & Setup

Follow these steps to set up the project locally on your machine:

Clone the repository:

git clone https://github.com/yourusername/Smart-Campus.git


Set up the local server:

Install and open XAMPP.

Move the cloned repository folder to the htdocs directory (e.g., C:\xampp\htdocs\Smart_Campus).

Start Apache and MySQL modules from the XAMPP Control Panel.

Database Configuration:

Open your web browser and go to http://localhost/phpmyadmin/.

Create a new database named smart_campus (1).

Import the provided SQL file (e.g., smart_campus (1).sql found in the /database folder) to set up the tables and schema.

Update the database credentials in the project's database configuration file (e.g., db.php).

Run the Application:

Open your browser and navigate to http://localhost/Smart_Campus.

Log in using the default Admin/Faculty/Student credentials.

🔮 Future Scope

The architecture of Smart Campus is highly scalable. Planned future enhancements include:

AI & Machine Learning: Predictive analytics for "at-risk" students and an AI-powered career guidance chatbot.

Mobile Application: Dedicated Android and iOS apps with push notifications and offline access.

Smart Attendance (IoT): Integration with RFID scanners or facial recognition at classroom entrances.

Payment Gateways: Secure modules for online fee payment and fine collection.

Blockchain Integration: Issuing tamper-proof digital transcripts and certificates.
